# 쇼핑몰 연동 리뷰

## 고객사 요구사항
>1. 페이지 연동으로, 상품 목록, 장바구니, 결제등 모든 페이지에서 이동이 자연스럽게 이루어짐과 동시에 사용자가 선택한 상품 데이터 유지.
>2. 장바구니에서 결제하기 누르면 카드 선택 (없으면 추가화면) 후 장바구니 결제 완료 창을 띄우기
>3. 페이지 간의 이동이 있어도 데이터 일관되게 유지하기. (데이터 일관성)
>4. 상품 클릭시 나타나는 상세페이지 상품에 대한 상세정보와 관련 상품(같은 브랜드)들을 보여주기


## 요구사항에 따른 기능 동작 확인


### 1. 모바일 환경 구성
예) 모바일 크롬, 삼성 브라우저에서 접속시 정상 동작함을 확인할 수 있습니다. 
(동작 확인 완료)

### 2. 페이지 연동
상품 목록, 장바구니, 결제등 모든 페이지에서 이동이 자연스럽게 이루어짐과 동시에 사용자가 선택한 상품 데이터 유지.
(동작 확인 완료)

### 3. 결제 완료 창 띄우기
장바구니에서 결제하기 누르면 카드 선택 (없으면 추가화면) 후 장바구니 결제 완료 창을 띄우기
(동작 확인 완료)

### 4. 데이터 일관성
페이지 간의 이동이 있어도 데이터 일관되게 유지하기.
(동작 확인 완료)

### 5. 상세 페이지 추가
각 상품의 상세 페이지를 추가하고, 상품 클릭시 나타나는 상세페이지 상품에 대한 상세정보와 관련 상품(같은 브랜드)들을 보여주기
