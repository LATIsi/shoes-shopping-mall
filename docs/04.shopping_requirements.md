## 📝 고객 요구사항 정리

## 📋 기능 목록
- 페이지 연동
  - 상품 목록, 장바구니, 결제등 모든 페이지에서 이동이 자연스럽게 이루어져야함
  예를 들어, 상품 목록-> 장바구니 이동하면서도 사용자가 선택한 상품데이터 유지 되어야함.
- 장바구니에서 결제하기 누르면 카드 선택 (없으면 추가화면) 후 장바구니 결제 완료 창을 띄워야 함.
- 데이터 일관성
  - 페이지 간의 이동이 있어도 데이터 일관되게 유지하기.
  장바구니에 담긴 상품이 상품목록이나 다른페이지에서도 장바구니에 담겼음을 명확히 보여주기
- 상세 페이지 추가
  - 상품 클릭시 나타나는 상세페이지 상품에 대한 상세정보와 관련 상품들을 보여주어야 함.
  - 관련 상품은 같은 브랜드의 상품을 보여주기. (3컬럼으로)
- 테스트 URL 제공
